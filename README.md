# Stroop Test 🎨

**▶ [Try it](https://renrenmimi.github.io/Stroop-Test/)** — runs in your browser, nothing to install.

The word says RED. The ink is blue. Your brain hesitates — that hesitation is the Stroop effect,
and this measures it.

## Modes

| Mode | Rule |
|------|------|
| **Classic** | respond to the ink color, ignore the word |
| **Reverse** | respond to the word, ignore the ink |
| **Mixed** | the rule flips on you mid-run |
| **Speed Blitz** | same task, far less time |

## Tech

Single-file HTML5 app. No build step, no dependencies.
